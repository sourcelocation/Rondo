Everything is on `https://rondo.matthewsource.com`: `/api` and `/media` (accounts, sharing, Discover, media, billing), and `/sync` (decks, notes and progress). The `/api` and `/media` pages are generated from the [OpenAPI contract](https://github.com/sourcelocation/rondo/blob/main/server/api/rondo.yaml), which the Go server's code is generated from too; `/sync` is described below.

## Authentication

Sign-in is [Ory Kratos](https://www.ory.sh/docs/kratos/self-service)'s API flows, at `https://rondo.matthewsource.com/auth`. They end with a session token, which every request sends as a bearer token, with the protocol version:

```bash title="Read your profile"
curl https://rondo.matthewsource.com/api/me \
  -H "Authorization: Bearer $RONDO_SESSION_TOKEN" \
  -H "Rondo-Protocol: 1"
```

A client the server no longer supports gets `426` with [`client_outdated`](/errors).

## Decks, notes and progress

Each device keeps its own copy and syncs records, not objects: there are no per-deck or per-note endpoints. A record is a row of one of six tables (decks, note types, notes, events, settings, smart decks), as JSON with its kind in `type`: `{"type": "note", "id": "…", "deck_id": "…", "fields": {"1": "hola"}, "v": 51…}`. Records carry a clock `v`; the newest version wins. Progress is a log of events (reviews, suspensions, flags, …), never overwritten.
