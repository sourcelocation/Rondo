---
title: Redeem a code
icon: Ticket
description: Turn a promo code into days of Pro.
---

Open the link that came with the code, or **Profile › Subscription › Redeem a code** in the web app, and enter it.

- A code gives Pro for a number of days. If you have Pro already, it starts when that ends.
- Each code works once, and some must be used by a date.
- While a subscription renews automatically, a code can't be added: turn renewal off first (**Manage subscription**).

When the days run out, Pro ends as described in [Free and Pro](/plans).
