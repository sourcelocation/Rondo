Open **Browse**. Type to search the notes' text; case and accents don't matter. Narrow it down with the filters:

| Filter | Shows                                                             |
| ------ | ----------------------------------------------------------------- |
| Deck   | Notes in a deck or its sub-decks.                                 |
| Type   | Notes of one note type.                                           |
| State  | Notes with cards that are new, learning, in review, or suspended. |
| Marked | Notes with a marked card.                                         |

Sort them by newest, recently changed, due soonest, or A–Z. The filters stay in the address, so going back or sharing the link keeps them.

Each note shows its deck, type, and when its next card is due. Choose a note to edit it; the list stays where it was.

## Change many notes

Select notes with their checkboxes (or **Select all**), then:

| Action   | Does                                                     |
| -------- | -------------------------------------------------------- |
| Move to… | Moves them to another deck.                              |
| Suspend  | Keeps their cards out of study; **Unsuspend** undoes it. |
| Mark     | Marks their cards for later; **Remove mark** clears it.  |
| Forget   | Makes their cards new again.                             |
| Delete   | Moves them to Recently deleted for 30 days.              |
