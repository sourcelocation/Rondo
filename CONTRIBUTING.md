# Contributing to Rondo

Issues and pull requests are welcome. For anything bigger than a fix, please open an issue first so we can agree on the approach.

Read [ARCHITECTURE.md](ARCHITECTURE.md) first. Changes to the API start in its contract, [`server/api/rondo.yaml`](server/api/rondo.yaml); the rules every write follows live once, in [`:core`](app/core).

## Contributor License Agreement

Before a pull request can be merged, you need to agree to the [Contributor License Agreement](CONTRIBUTOR_LICENSE_AGREEMENT.md). You keep the copyright in your contribution. The agreement lets the project include it under the AGPL-3.0 and also relicense it later, for example to offer commercial licenses.

To agree, tick the checkbox in the pull request template. If you can't use GitHub for this, email support@matthewsource.com.
